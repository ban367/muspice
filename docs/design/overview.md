# 概要: 背景・目的・スコープ

## 背景と課題

Muspiceは、ローカル音楽ファイルをデスクトップで一元管理するためのアプリケーションです。既存の汎用プレーヤーでは、以下の点が開発要件として不足していました。

- フォルダ単位の再帰インポートと重複処理（Skip/Replace）の統合
- DB更新のみ / ファイルタグ更新込みを切り替えられるメタデータ編集
- ローカルSQLiteとFTS5を使った高速検索・フィルタリング
- プレイリスト管理、再生統計（お気に入り・レーティング・再生回数）の統合

## 目的

- ローカル完結（外部通信なし）で動作する音楽管理環境を提供する
- メタデータ編集と検索性を強化し、ライブラリ運用コストを下げる
- Tauri + Rust + SQLiteで、デスクトップ向けに軽量かつ応答性の高い実装を維持する

## 成功指標

| 指標           | 目標                                                           |
| -------------- | -------------------------------------------------------------- |
| 検索開始遅延   | 入力停止から300ms以内に検索処理開始（デバウンス）              |
| 一覧取得       | `tracks`の取得上限1000件以内で安定動作                         |
| インポート処理 | 50件単位トランザクションで大量ファイルでも失敗時の影響を局所化 |
| UI応答性       | 100曲以上で仮想スクロールを利用して描画負荷を抑制              |

## 対象ユーザー

- プライマリ: ローカルに保持した音楽ファイルを整理・再生したい個人ユーザー
- セカンダリ: タグ編集や再生統計を使って音楽ライブラリを継続運用するユーザー

## スコープ

### In Scope

- 音楽ファイルのインポート（MP3/FLAC/WAV/M4A）
- メタデータの単体/複数編集、バリデーション
- プレイリスト作成・編集・削除・並び替え
- 再生（現在曲管理、アルバムアート取得、ファイル位置表示）
- 検索/フィルタ、グループ表示（アルバム/アーティスト/ジャンル）
- 再生統計（お気に入り・レーティング・再生回数・履歴）

### Out of Scope

- クラウド同期、ユーザーアカウント、外部API連携
- ストリーミング配信サービスの統合
- マルチデバイス同期やサーバーサイド機能
